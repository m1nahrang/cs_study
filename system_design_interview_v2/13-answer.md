1. KDB+에 대해 설명해주세요.
- 인메모리 DB기능을 갖춘 열 기반 관계형 시계열 데이터 베이스
- 고주파 트레이딩에서 대규모 데이터 세트를 고속으로 저장,분석, 처리, 검색하는 데 사용됨.
- 금융기관에서 주식이나 상품거래소 데이터 등 시게열 데이터를 분석하기위해 사용.
2. mmap에 대해 설명해주세요.
- mmap(memory-mapped file)은 파일 또는 디바이스를 프로세스의 메모리 공간에 매핑해 마치 메모리처럼 파일을 읽고 쓸 수 있도록 하는 시스템 콜
-> 파일을 디스크에서 직접 읽는 대신, 해당 파일을 가상 메모리에 매핑해 포인트처럼 접근할 수 있게함.
- 고속접근
  -- 파일 내용을 직접 읽기/쓰기하지 않고 메모리 주소 통해 접근 (read()/write() 시스템 콜을 줄여 컨텍스트 스위칭 비용 절감)
- 공유 메모리 가능
  -- 여러 프로세스가 같은 파일을 매핑해 IPC 용도로 사용 가능
- 쓰기 버퍼링
  -- 변경사항은 메모리에만 반영되며, 디스크에 동기화 가능
